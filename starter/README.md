# はじめに（AI分身の仕事用フォルダ）

このフォルダが、あなたの AI 分身の仕事場です。好きな名前に変えて使ってください（例：`山田AI`）。

1. Claude のデスクトップアプリの **Code** タブ（またはターミナルの `claude`）で、このフォルダを開く
2. 「このフォルダを信頼しますか？」→ **信頼する**（プラグインが自動で入ります）
3. 「**セットアップして**」と話しかける

セットアップが終わると、このフォルダに次のものができます：

| 場所 | 中身 |
|---|---|
| `CLAUDE.md` | あなたの設定（呼び方・部署・定例の仕事など）。AI と話しながら育てます |
| `設定/config.json` | AI が使う設定（時刻・部署など） |
| `00_タスク管理/タスク管理.xlsx` | タスクの一覧・あなたへのお願い・今日の予定 |
| `02_成果物/` | AI が作ったもの |
| `03_インプット/` | あなたが AI に渡すデータを置く場所（AI は読むだけ） |

`.claude/settings.json` には、AI が削除・送信・設定の変更などをしないための設定と、プラグインを入れる設定が入っています。消したり書き換えたりしないでください。

プラグインをやめるとき・オフにするときは、アプリを一度終了して開き直してください（開いたままだと NG の見張りが残ります）。やめたあとも、このフォルダでは `.claude/settings.json` の止める設定が効き続けます。外し方はプラグインの README の「やめるとき・止めるとき」を見てください。
