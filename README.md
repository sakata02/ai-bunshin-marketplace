# Shadow Desk（中の名前は ai-bunshin）— あなたの仕事を代わりに進める Claude Code プラグイン【β版】

以前の名前：AI分身

> **β版です。** 動作の保証はありません（MIT ライセンス。自己責任でお使いください）。不具合や「分かりにくい」は [Issues](../../issues) へ。返事は無理のない範囲で行います。
> これは **オープラン株式会社** が作った非公式のプラグインです。Anthropic の公式のものではありません。

「これやっといて」と雑に頼むだけで、AI の指揮官が仕事を分けて、部下の AI たちが作り、確かめ、あなたにしかできないことだけを **期日と手順付きで** お願いしてくる ― そんな「Shadow Desk」を、Claude Code の上に作るプラグインです。使うほど、あなたの仕事のやり方に合わせて良くなっていきます。

## できること

- **指揮官＋部下7人**：指揮官（Opus を推奨）が依頼を分析し、部下（Sonnet）に振り分けます
  - 資料の作成・検証／開発の実装・検証／構成・デザイン／データ分析・集計／研修の教材作り
  - 使わない部下は止められます。部下を増やすのは、あなたの承認があったときだけです
- **タスク管理**：AI のタスク・あなたへのお願い・あなた自身の仕事を、Excel（タスク管理.xlsx）で見られます。完了予定日は自動で計算します
  - 「タスク追加：◯◯（〆11/5）、△△」と話しかけるだけで、自分の仕事も登録できます。AI が引き受けられる部分は提案します
- **1日のスプリント**：朝に計画してそのまま実行、夕方に振り返り（Mac では自動。ほかは「今日の計画して」「振り返りして」で）
  - 振り返りの改善（Try）で、ルールが少しずつ育ちます。ルールの変更はあなたの承認制です
  - 金曜には、業務改善（システム化）の提案を最大3件出します
- **開発**：「設計しといて」は設計まで、「作って」は実装まで。自分のフォルダで完結／Git のリポジトリ／Spec Kit の案件、を人ごとに選べます
- **今日の予定**：Google カレンダーとつなぐと、今日の予定をタスクと一緒に見られます（読むだけ）
- **コックピット（任意。右のパネルのこと。中の名前は ai-bunshin-panel）**：今日のやること・予定・お願いを、Claude の右に出しっぱなしにできます（ターミナル版だけ。デスクトップアプリでは動きません。入れ方は下の B）
- **あなたの文章らしさ**：記事やコラムは、あなたが OK した文章と手直しから「あなたらしさ」を育てます
- **やってはいけないこと（NG）を止める**：削除・送信・権限の変更・共通部分の書き換えなどを、権限の設定と実行前の見張りの2重で止めます

## 必要なもの

- **Claude Code**（ターミナル版、またはデスクトップアプリの「Code」タブ）と、Claude のアカウント
  - 使用量は、使う人それぞれの Claude のプランから出ます
- **Python 3** と **openpyxl**（Excel を作るため）。入っていなければ、初回セットアップが入れ方を案内します
  - Python が無いと、NG の見張り（実行前のチェック）も動きません。必ず入れてから使ってください
- **Windows** の場合：[Git for Windows](https://git-scm.com/downloads/win)（Git Bash）と [Python](https://www.python.org/downloads/)。朝・夕方の自動実行は Mac だけです（Windows では「今日の計画して」「振り返りして」と話しかけます）
  - Windows で自動に回したいときは、Claude デスクトップアプリの「定期実行（Scheduled）」を使う方法があります（PC が起きていて、アプリが開いているときだけ動きます）。手順は、セットアップ（`/ai-bunshin:setup` の「5. 自動実行」の「Windows の人」）が案内します。うまくいかなければ、手で話しかける方法で十分回ります。【β版・一部は動作未確認】
  - Python は入れるときに「Add python.exe to PATH」にチェックを入れてください。Windows では `python3` が無く `python`・`py` になることがありますが、hook と AI は自動で読み替えます

## 入れ方

ターミナルを使ったことがなければ **A**、ふだんターミナルで Claude Code を使っていれば **B** がおすすめです（どちらも中身は同じです）。

### A. デスクトップアプリ・チャットだけで使う（コマンド不要）

1. Claude のデスクトップアプリの設定画面で「プラグイン」→「追加」→「マーケットプレイスを追加」を開き、`https://github.com/sakata02/ai-bunshin-marketplace` を貼る
2. 出てきた「Shadow Desk（ai-bunshin）」（古い版では「AI分身」と表示）を入れる（コックピット（ai-bunshin-panel）も別のプラグインとして出ますが、デスクトップアプリでは動かないので入れなくて大丈夫です）
3. 仕事用のフォルダを1つ作り（例：`山田AI`）、**Code** タブでそのフォルダを開く【未確認】
4. 「**セットアップして**」と話しかける。質問に答えると、あなた用の設定・タスク表・ナレッジができて、任せられる仕事の候補が出ます【未確認】

- 手順1・2（マーケットプレイスの追加と、プラグインを入れるボタン）は、実際に試して確かめました。次の版からプラグインの表示名が「Shadow Desk」になります。それまでは画面に「AI分身」と出ることがあります。手順3・4（新しいフォルダでのセットアップ）はまだ確かめていません【未確認】
- 注意：削除・送信などを止める設定（`.claude/settings.json` の deny）は、セットアップがそのフォルダに書きます。入れたら、ほかの仕事を頼む前に、まずセットアップをしてください
- 更新は「更新」の節を見てください

コックピットは、ターミナル版（B）で入れる方法だけ案内しています。デスクトップアプリでは動きません（`/yarukoto` も使えません）。デスクトップアプリで今日のやることを見たいときは、（セットアップのあとで）「状況は？」「今日の計画見せて」と話しかけてください（スキル `/ai-bunshin:status` が見せます）。

#### 別の方法：starter フォルダを使う

止める設定が最初からフォルダに入っている方法です。

1. このページの右上「Code」→「Download ZIP」でダウンロードし、展開する
2. 中の **`starter`** フォルダを、好きな場所にコピーして、名前を変える（例：`山田AI`）
3. Claude のデスクトップアプリの **Code** タブでそのフォルダを開く（「このフォルダを信頼しますか？」と聞かれたら **信頼する**）。少し待つと、プラグインが自動で入る（「Plugins changed」と出たら、表示に従って読み込み直す）
4. 「**セットアップして**」と話しかける

### B. ターミナル（CLI）で使う

```bash
# 1. 配布元を登録してプラグインを入れる
claude plugin marketplace add sakata02/ai-bunshin-marketplace
mkdir -p ~/workspace/<名前>-ai && cd ~/workspace/<名前>-ai
claude plugin install ai-bunshin@ai-bunshin-marketplace --scope project

# 2. 起動して、セットアップ
claude
# →「セットアップして」（または /ai-bunshin:setup）

# 3.（任意）コックピットを入れる。入れたら Claude を開き直す
claude plugin install ai-bunshin-panel@ai-bunshin-marketplace --scope project
```

3 を入れると、Claude の右にコックピットが開き、「今日のやること・予定（カレンダーをつないだ人だけ）・お願い」が出ます。`/yarukoto` で今日の一覧、`/task T013`（T013 は例。実際の ID はコックピットの一覧に出ます）でそのタスクの詳細を開けます。あなたの仕事用フォルダの中だけで出て、ほかのフォルダでは出ません。

Mac なら、セットアップの最後に案内されるコマンドで、朝・夕方の自動実行を登録できます。Windows は、デスクトップアプリの定期実行（案内あり）か、朝「今日の計画を立てて」・夕方「今日の振り返り」と話しかける方法で回します。

## 使い方の例

| 言い方 | どうなるか |
|---|---|
| 「来月の研修資料作っといて」 | タスクに登録 → 翌朝の計画で、部下が作って確かめる |
| 「今すぐ ◯◯の文面整えて」 | その場で対応 |
| 「タスク追加：経費精算（〆11/5）、面接2名」 | あなた自身の仕事として登録。AI が手伝える部分を提案 |
| 「何を頼めばいい？」 | あなたの部署や定例から、任せられる仕事と頼み方の例を出す |
| 「T012 やった」 | お願いを完了にして、次の作業へ |

見る場所：仕事用フォルダの `00_タスク管理/タスク管理.xlsx` と `<呼び方>へのお願い.md`

## 知っておいてほしいこと

- **あなたの仕事のデータは、あなたのフォルダにだけ置かれます**。このプラグインが仕事のデータを外部に送ることはありません（Claude 自体とのやりとりは、通常の Claude Code と同じです）
  - 例外：Google カレンダーをつないだ場合は、カレンダーの非公開 URL から予定を **読み込みます**（送るものはありません）。読んだ予定の件名と時間は、フォルダの中（`00_タスク管理/data/calendar_cache.json`）に残ります
- **NG の見張りは完全ではありません**。文字の並びで判断しているため、すり抜ける書き方があり得ます。大事なファイルはバックアップを取ってください
- **秘密の情報（パスワード・API キー）は、設定ファイルやチャットに書かないでください**。Google カレンダーの非公開 URL も、Mac のキーチェーンに入れる案内をします（Windows などキーチェーンが無い環境では、ユーザーのフォルダ直下の `ai-bunshin-calendar-url.txt` に書く案内をします。あなたのフォルダの外なので、同期や Git には載りません）
- プラグインの共通部分（このリポジトリの中身）は、各自の環境の AI からは書き換えないようにしています。改善の提案は、あなたのフォルダに下書きが作られます。よければ Issues へ

## やめるとき・止めるとき

- プラグインをオフ・削除したら、**Claude のアプリ（ターミナルなら `claude`）を一度終了して開き直してください**。開いたままのセッションには NG の見張りが残り、外部への接続（`curl` など）やファイルの書き込みが止まったままになります
- セットアップした（または starter を使った）フォルダには、`.claude/settings.json` に止める設定（`permissions.deny`）が残ります。プラグインをやめたあとも、そのフォルダでは `curl`・`ssh`・`git push` などが止まります。止めたくないときは、`deny` の中の該当する行（例 `"Bash(curl:*)",`）を消して保存し、開き直してください。そのフォルダの外には効きません
