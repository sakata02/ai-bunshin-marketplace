# AI分身（ai-bunshin）【β版】

「これやっといて」と雑に頼むだけで、AI の指揮官が仕事を分けて、部下の AI たちが作り、確かめ、あなたにしかできないことだけを期日と手順付きでお願いしてくる、Claude Code のプラグインです。

> β版です。動作の保証はありません（MIT ライセンス。自己責任でお使いください）。オープラン株式会社が作った非公式のプラグインで、Anthropic の公式のものではありません。
> くわしい説明・入れ方（A. デスクトップアプリ／B. ターミナル）は、配布元のリポジトリの README にあります。このファイルは、プラグインの中に入れた短い案内です。

## はじめかた

1. 仕事用のフォルダを Claude Code（デスクトップアプリの **Code** タブ、またはターミナルの `claude`）で開く
2. 「**セットアップして**」（または `/ai-bunshin:setup`）と話しかける。質問に答えると、あなた用の設定・タスク表ができて、任せられる仕事の候補が出ます
3. そのあとは、雑に頼むだけです。「来月の研修資料作っといて」「何を頼めばいい？」「状況は？」「T012 やった」

見る場所：仕事用フォルダの `00_タスク管理/タスク管理.xlsx` と `<呼び方>へのお願い.md`

## 必要なもの

- Claude Code と Claude のアカウント
- Python 3 と openpyxl（Excel を作るため）。入っていなければ、セットアップが入れ方を案内します。Python が無いと、NG の見張り（実行前のチェック）も動きません
- Windows の場合：Git for Windows（Git Bash）と Python。朝・夕方の自動実行は Mac だけです（Windows では「今日の計画を立てて」「今日の振り返り」と話しかけます。デスクトップアプリの定期実行を使う方法は、セットアップが案内します）

## コマンドの打ち方

案内の中に `! python3 --version` のようなコマンドが出てきたとき：

- `!` を頭に付けて、Claude の入力欄で打つと、そのコマンドがその場で実行され、結果が会話に出ます。`!` を付けないと、ふつうの文章として AI に送られます
- Claude を開く前に打つもの、`!` が効かない画面のときは、`!` を付けずに、Mac は「ターミナル」、Windows は「PowerShell」に打ちます
- カレンダーの URL など秘密の値を扱うコマンドは、`!` を使わず、必ずターミナルで打ちます（チャットに残さないため）

## ことばの説明

「スプリント」「ベロシティ」「約束pt」「PDCA」「KPT」などの言葉は、`/ai-bunshin:status` の最後の「ことばの説明」に、ひらがな多めで書いてあります。「言葉の意味を教えて」と聞いても説明します。

## 知っておいてほしいこと

- あなたの仕事のデータは、あなたのフォルダにだけ置かれます。このプラグインが仕事のデータを外部に送ることはありません（Claude 自体とのやりとりは、通常の Claude Code と同じです）
- NG の見張りは完全ではありません。文字の並びで判断しているため、すり抜ける書き方があり得ます。大事なファイルはバックアップを取ってください
- 秘密の情報（パスワード・API キー）は、設定ファイルやチャットに書かないでください
- 変更の記録は `CHANGELOG.md` にあります

## やめるとき・止めるとき

- プラグインをオフ・削除したら、**Claude のアプリ（ターミナルなら `claude`）を一度終了して開き直してください**。開いたままのセッションには NG の見張りが残り、外部への接続（`curl` など）やファイルの書き込みが止まったままになります
- セットアップした（または starter を使った）フォルダには、`.claude/settings.json` に止める設定（`permissions.deny`）が残ります。プラグインをやめたあとも、そのフォルダでは `curl`・`ssh`・`git push` などが止まります。止めたくないときは、`deny` の中の該当する行（例 `"Bash(curl:*)",`）を消して保存し、開き直してください。そのフォルダの外には効きません
