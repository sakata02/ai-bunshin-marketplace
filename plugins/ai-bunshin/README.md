# AI分身（ai-bunshin）【β版】

「これやっといて」と雑に頼むだけで、AI の指揮官が仕事を分けて、部下の AI たちが作り、確かめ、あなたにしかできないことだけを期日と手順付きでお願いしてくる、Claude Code のプラグインです。

> β版です。動作の保証はありません（MIT ライセンス。自己責任でお使いください）。オープラン株式会社が作った非公式のプラグインで、Anthropic の公式のものではありません。
> くわしい説明・入れ方（A. デスクトップアプリ／B. ターミナル）は、配布元のリポジトリの README にあります。このファイルは、プラグインの中に入れた短い案内です。

## はじめかた

1. 仕事用のフォルダを Claude Code（デスクトップアプリの **Code** タブ、またはターミナルの `claude`）で開く
2. 「**セットアップして**」（または `/ai-bunshin:setup`）と話しかける。質問に答えると、あなた用の設定・タスク表ができて、任せられる仕事の候補が出ます
3. そのあとは、雑に頼むだけです。「来月の研修資料作っといて」「何を頼めばいい？」「状況は？」「T012 やった」

見る場所：仕事用フォルダの `00_タスク管理/タスク管理.xlsx` と `<呼び方>へのお願い.md`

## 必要なもの

- Claude Code と Claude のアカウント
- Python 3 と openpyxl（Excel を作るため）。入っていなければ、セットアップが入れ方を案内します。Python が無いと、NG の見張り（実行前のチェック）も動きません
- Windows の場合：Git for Windows（Git Bash）と Python。朝・夕方の自動実行は Mac だけです（Windows では「今日の計画を立てて」「今日の振り返り」と話しかけます。デスクトップアプリの定期実行を使う方法は、セットアップが案内します）

## コマンドの打ち方

案内の中に `! python3 --version` のようなコマンドが出てきたとき：

- `!` を頭に付けて、Claude の入力欄で打つと、そのコマンドがその場で実行され、結果が会話に出ます。`!` を付けないと、ふつうの文章として AI に送られます
- Claude を開く前に打つもの、`!` が効かない画面のときは、`!` を付けずに、Mac は「ターミナル」、Windows は「PowerShell」に打ちます
- カレンダーの URL など秘密の値を扱うコマンドは、`!` を使わず、必ずターミナルで打ちます（チャットに残さないため）

## ことばの説明

「スプリント」「ベロシティ」「約束pt」「PDCA」「KPT」などの言葉は、`/ai-bunshin:status` の最後の「ことばの説明」に、ひらがな多めで書いてあります。「言葉の意味を教えて」と聞いても説明します。

## 知っておいてほしいこと

- あなたの仕事のデータは、あなたのフォルダにだけ置かれます。このプラグインが仕事のデータを外部に送ることはありません（Claude 自体とのやりとりは、通常の Claude Code と同じです）
- NG の見張りは「うっかり防止の安全ベルト」で、完全ではありません。くわしくは次の「NG の見張り（hook）について」を読んでください。大事なファイルはバックアップを取ってください
- 秘密の情報（パスワード・API キー）は、設定ファイルやチャットに書かないでください
- 変更の記録は `CHANGELOG.md` にあります

## NG の見張り（hook）について

プラグインには、AI が Bash（コマンド）とファイルを書く道具を使う**直前**にチェックする「NG の見張り」（hook）が入っています。役割は、AI のうっかりや、資料・Web ページに紛れた指示で、困る操作が実行されるのを前もって止める**安全ベルト**です。守りの本体ではありません。

**止めるもの**（実物は `scripts/ng_guard.py`）

- ファイルを書く道具（Write・Edit・MultiEdit・NotebookEdit）で、元データ（`03_インプット/`）、`.claude/settings.json`、`.claude/hooks/`、共通ルールの自動コピーなどを書き換えること
- Bash（コマンド）での、削除（`rm` など）、`git reset --hard` などの取り消しにくい git 操作、プロセスの停止、システムの変更（`launchctl`・`crontab` など）、権限の変更（`chmod` など）、インストール、外部への送信（`curl`・`ssh`・`git push`・`gh`・メールなど）
- Bash での、`>`・`>>`・`cp`・`mv`・`tee` などによる、元データ（`03_インプット/`）、`.claude/settings.json`・`.claude/settings.local.json`、`.claude/hooks/`、共通ルールの自動コピーへの書き込み
- Bash での、`sed -i`・`perl -i` で、`.claude/`・`CLAUDE.md`・`設定/` から始まる相対パスで指定した書き換え
- Bash での、`dd of=`・`cp /dev/null`・`: >`・`>|` など、ファイルを空にする書き方
- python などのスクリプトを通した削除・送信、設定やプラグインのコピーへの書き込み（コマンドに書かれた Python の中の、引用符でくくった書き込み先を見ます）

**限界**
- メールや Slack などのコネクタ（MCP）での送信や、`WebFetch`・`WebSearch` などの Web 取得の道具は、見張りでは止まりません。見張りが掛かる道具は、Bash・Write・Edit・MultiEdit・NotebookEdit だけです
- 判断は、コマンドや書き込み先の文字の並び（正規表現）を読んで行います。そのため、止められない書き方があります（変数や展開を使った書き方など）。逆に、止めなくてよい操作を止めてしまうこともあります
- Python 3 が無いと動きません。動かないときは止める働きをしないので、先に Python 3 を入れてください
- あなたの仕事用フォルダの中で動くのが基本です。ほかのプロジェクトでは、ふだんの作業は止めません。ただし、プラグイン本体のコピー（`~/.claude/plugins/`）への書き込みなどは、どこでも止めます

**本当の守り**
安全のために頼るのは、Claude Code 自身の仕組みです。
- **権限の設定（permissions）**：`.claude/settings.json` の `deny`・`allow` で、使える道具や操作を決めます。セットアップでは、止める行（`deny`）が入ります
- **サンドボックス**：Claude Code の機能で、OS の力でコマンドの書き込み先や通信先を制限します。既定では無効です。Mac・Linux・WSL2 で使え、Windows のそのままの環境では使えません。使うときは Claude Code の公式の説明を見て、あなたが設定します。Claude Code の説明では、効くのはコマンド（Bash）とそこから動くものだけで、ファイルを書く道具は権限の設定で守ります

大事なデータには、この見張りだけに頼らず、権限の設定とバックアップを組み合わせてください。

## 自動実行の Python と囲い

朝・夕方の自動実行（Mac だけ）の、実行の段だけは、Claude Code のサンドボックス（囲い）で Bash を囲み、点検で全部止まった日だけ、その中で Python を使えるようにします。会話の中は今までどおりです。計画の段と振り返りの段では、決まった2つのスクリプトのほかには Python を許しません。上の「サンドボックス」の、あなたが設定する囲いとは別です。

- **毎回の点検**：実行の段の前に、囲いが効いているかを点検します。囲いの中から、守る先に書けないこと、カレンダーの取得先以外へ通信できないこと、キーチェーンの項目を見つけられないことなどを確かめ、全部止まった日だけ Python を許します
- **点検が通らない日**：点検が通らない・確かめられない・時間切れの日は、Python なしで動き、通知が1行出ます。囲いの設定を作れなかった日も Python なしで動きますが、こちらはログに残るだけで、通知は出ません。設定は作れたのに囲いを起動できず止まった日は、その日の実行は失敗で終わり、囲いなしでやり直すことはしません
- **囲いが守るもの**：囲いが書き込みと通信を制限するのは、Bash とそこから動くものだけです。守る先は、`設定/`、`CLAUDE.md`、`CLAUDE.local.md`、`03_インプット/`、`.claude/`、`scripts/`、`.git`、見張りの記録（`~/.ai-bunshin/`）、`~/Library/LaunchAgents`、`~/.claude` の設定（`settings.json`・`CLAUDE.md`・`skills`・`agents`・`commands`）、プラグインのコピー（`~/.claude/plugins/`）、プラグイン本体のフォルダです。通信は、カレンダーの取得先以外へはできません
- **守る先に入っていない先**（例：`02_成果物/`）には、Python から書けますし、消せます。あなたの仕事用フォルダの中にある入れ子のリポジトリ（`05_開発/<案件>/.git`）、`PATH` のフォルダ、下の階の `CLAUDE.md`、自動メモリ、ベアリポジトリも、守る先に入れていません（あなたの仕事用フォルダの外から追加するリポジトリの `.git` は守ります）
- **見張りと囲いの外**：見張りは、コマンドに書かれた Python の書き込み先の文字までを見て、Python のファイルの中身は読みません。ファイルを書く道具（Write・Edit）、MCP、`WebFetch` は囲いの外です。ファイルを書く道具は権限の設定で止めますが、その範囲が囲いの守る先と同じになるのは、囲いを付けた日です。囲いなしの日は、決まった `deny` だけになります
- **キーチェーン**：点検で、囲いの中からキーチェーンの項目を見つけられないことを確かめ、見つけられた日は Python を許しません。確かめる項目がない Mac では、毎日 Python なしになります。実行の段では `WebFetch` も使えます。点検が見るのはキーチェーンだけで、それ以外の秘密の読み取りは守っていません
- **設定に Bash の許可がある場合**：あなたの仕事用フォルダの `.claude/settings.json`・`.claude/settings.local.json`、ホームの `~/.claude/settings.json` の `allow` に Bash（や MCP）の許可を入れていると、点検の結果の偽造は防げません。止めずに続け、ログに1行出ます。管理者が配る設定（managed-settings）は読まないので、そこに許可があっても、ログには出ません
- **マーケットプレイスのフォルダを守る範囲**：マーケットプレイスのフォルダを守るのは、マーケットプレイスが手元のフォルダ（directory）から入っているときだけです。読めない・無い・手元のフォルダでないものは、守る先に足さずに進みます。場所が書かれていても使えない形（相対パス・使えない文字・ルート）のときは囲いを作らず、その日は Python なしで動きます

## やめるとき・止めるとき

- プラグインをオフ・削除したら、**Claude のアプリ（ターミナルなら `claude`）を一度終了して開き直してください**。開いたままのセッションには NG の見張りが残り、外部への接続（`curl` など）やファイルの書き込みが止まったままになります
- セットアップした（または starter を使った）フォルダには、`.claude/settings.json` に止める設定（`permissions.deny`）が残ります。プラグインをやめたあとも、そのフォルダでは `curl`・`ssh`・`git push` などが止まります。止めたくないときは、`deny` の中の該当する行（例 `"Bash(curl:*)",`）を消して保存し、開き直してください。そのフォルダの外には効きません
