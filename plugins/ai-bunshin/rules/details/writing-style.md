## 文章のスタイルを育てる（記事・コラムなど、本人名義の文章）

本人らしさの再現性を、出すたびに上げていく。中身はすべて本人のフォルダの `04_ナレッジ/記事スタイル/` にある。

| ファイル | 中身 |
|---|---|
| `書き方.md` | 文体・ユーモアの型・守ること・構成・入稿の流れ |
| `言い回し.md`（本人設定で別名にしてよい） | よく使う言い回し、ボケの型の実例、使わない言い回し |
| `お手本/<日付>_<記事名>/` | 本人が OK を出して公開した最終バージョンと画像。README に承認日と「どこが良かったか」 |
| `手直し記録.md` | 記事ごとの「AI の下書き → 本人の最終バージョン」の違い、分かったこと、**手直しの量**（変わった文字の割合）の推移 |

1. **書く前**：書き方・言い回し・お手本の新しいもの2〜3本を読む（全部は読まない）
2. **公開のお願い** の `report_back` に「公開した最終バージョン（直したところがあればそのまま。無ければ『そのまま』）」を入れる
3. **公開後**：下書きと最終バージョンを比べ、手直し記録に書く。最終バージョンをお手本に足す（本人が OK した記事だけ）。書き方・言い回しに足したい点は「ルール変更の承認」（行き先：本人）として出す
4. 手直しの量が下がっていくかで、近づいているかを確かめる。本人名義の冗談や本人の行動として書いた事実は、公開前に本人に確認する
