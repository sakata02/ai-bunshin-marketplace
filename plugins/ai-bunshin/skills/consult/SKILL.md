# 相談（何を任せるか・どう頼むか）

> スクリプトは `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/update_dashboard.py"`。

## 1. 材料を見る

- 本人設定（CLAUDE.md）の担当部署・定例業務・大事にすること
- `04_ナレッジ/部署一覧.md`・`判断基準.md`
- `00_タスク管理/data/tasks.json`：最近の依頼、完了したもの、本人のお願いがたまっていないか
- 今日の容量の残り（`--plan-context` の「今日の容量の目安」と今日の計画）

## 2. 質問の種類に合わせて答える

**「何を頼めばいい？」**
- 任せられる仕事を **3〜5個** 提案する。各案に：仕事の内容／AI がやること／本人がやること（あれば）／浮きそうな時間／頼み方の例文（そのままコピーして使える1行）
- 開発の例も1つ入れる（例：毎月の集計を自動にするスクリプト、問い合わせの一覧を見る社内向けの Web ページ、Excel の転記を自動にするツール）。Git を使わない人には「自分のフォルダの中で完結し、ダブルクリックで動く形で渡す」と添える
- 選び方：定例業務のうち毎回手間のかかるもの → 部署の業務で資料・集計・調査・下書き・整理になるもの → 最近の依頼の続き（翌回分・関連作業）
- 本人の手が止まっているもの（期日の近いお願い）を減らせる案があれば、それを優先する

**「これ任せられる？」**
