# コックピット（タスク表）を見せる

自動実行（`claude -p`）の中では使わない。会話の中で、本人に頼まれたときだけ動く。対話の最中に hook の出力に「⏳ 自動実行中」があっても、それは別の実行のことなので使ってよい（自分の実行かどうかは `lock_check.py` の1行目で決める）。

1. `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/update_dashboard.py"` を実行する（ガントの元の forecast.json が今日のものになる）。`python3` が動かないときは `python`、それも動かなければ `py -3` の順に試す。本人のフォルダが見つからないという出力なら、「00_タスク管理 があるフォルダで Claude を開き直してください」と伝えて終わる

2. あなたが今使える道具の一覧に `mcp__ai-bunshin__open_task` があるとき（検索しないと呼べない道具として載っているときは、1回だけ検索して呼べるか確かめる。呼べなければ手順3へ）は、HTML は作らない。`open_task` を id を空にして呼び、次の1行だけを伝えて終わる：
   - 「右のパネルに出しました。ガントは『ガント見せて』と言ってください」

3. 道具が無い・呼べないとき（デスクトップアプリなど）は、HTML を作って開く：
   1. `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/cockpit_html.py"` を実行する（`python3` が動かないときは `python`、`py -3` の順）。終了コードが 0 で、出力に `00_タスク管理/コックピット.html` のパスが1行出たときだけ、次へ進む。終了コード 1（本人のフォルダの中ではない・書けなかった）か 2 のときは、何も開かず、出力の1行をそのまま本人に伝えて終わる
   2. 開く。上から順に試し、開けたら止める：
      - (a) 既定のブラウザ：Mac は `open "<出力されたパス>"`、Windows は `cmd //c start "" "<出力されたパス>"`（Windows は動作未確認）。それ以外の OS は開かずに (c) へ
      - (b) 内蔵のブラウザの道具が使えるときは、`file://<出力されたパス>` を1回だけ開いてみる（開けない・断られたら次へ。繰り返さない）
      - (c) どちらも開けなかったら、パスを伝える（本人が自分で開く）。あわせて、会話の中に次の3つだけ短く出す：「今日まで」（本人のやること）・「AI の今日の計画」・「お願いの件数」。出す中身は、手順1で `update_dashboard.py` が出した内容と `00_タスク管理/data/tasks.json` から取る
   3. 開けたら、「タスク表を開きました。新しくするには『コックピット見せて』と言ってください」と1行伝える

- アーティファクトは使わない。HTML は `00_タスク管理/コックピット.html` の1つだけで、予定の件名が入るので、本人のフォルダの外へ送らない
- HTML の中身は、右のパネルと同じ区切り（今日まで・予定・AI の今日の計画・AI のこれから・試し中の Try・近いうちに・ガント・全部のタスク）。行を押しても詳細は出ない（詳細はパネルの `open_task` だけ）
