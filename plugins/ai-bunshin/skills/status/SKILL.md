# タスク状況の確認

0. **エラーの見分けと言い換え**：スクリプトの出力やエラーが次のどれかなら、英語のエラーや内部の名前をそのまま見せず、本人に分かる言葉で返す（続けて、わかる範囲の状況報告もする）
   - `openpyxl` が無い（ModuleNotFoundError、または「openpyxl が入っていないため、Excel の更新を飛ばしました」）→ 「Excel（タスク管理.xlsx）を作る部品が入っていないので、Excel の更新だけ飛ばしました。タスクボードとお願いの一覧は更新しています。入れるには `! python3 -m pip install --user openpyxl`（Windows は `! py -3 -m pip install --user openpyxl`）を打ってください（`!` を頭に付けて Claude の入力欄で打つと、その場で実行されます。`!` が効かない画面では、`!` を除いてターミナルで打ちます）」（AI は自分でインストールしない）
   - Excel が開かれていて保存できない（「Excel で開かれているため保存できませんでした」）→ 「タスク管理.xlsx を閉じてから、もう一度 /ai-bunshin:status と言ってください」
   - 本人のフォルダが見つからない（「本人のフォルダ（00_タスク管理/data/tasks.json と 設定/config.json）が見つかりません」）→ 「00_タスク管理 があるフォルダで Claude を開き直してください」
1. `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/update_dashboard.py"` を実行する（Excel とタスクボードが更新される）
2. 出力をもとに、本人に次の形で短く報告する：

```

優先順位トップ5
1. T0XX タイトル（担当）— 完了予定 M/D

要対応：（期限超過・遅延見込みのタスクと、対処案）

📌 <呼び方>へのお願い（N件）
- T0XX [判断] 内容

（手順は 00_タスク管理/<呼び方>へのお願い.md にあります）
```

3. 期限超過や遅延見込みがあれば、対処案（順位の入れ替え、分割、部下の並列化など）を1〜2個添える
4. 上の手順0のエラーが出たときは、言い換えて伝える

詳細は `00_タスク管理/タスク管理.xlsx` を開けば見られる、と案内する。

## 「今日の計画見せて」と言われたとき

- 今日の計画（`01_スプリント/<今のスプリント>/daily/YYYYMMDD_計画.md`、YYYYMMDD は今日）があれば、読んで見せる（読むだけ。直さない）
- 無ければ「まだ計画がありません。/ai-bunshin:daily-plan で立てられます」と案内する

## ことばの説明（本人に聞かれたとき・報告に使うときに添える）

報告や Excel に出てくる言葉は、本人がエンジニアでなくても分かるように、使うときに次の言い方で一言添える。聞かれたら表ごと見せる。

| ことば | 意味（ひらがな多め） |
|---|---|
| スプリント | きめた期間（ここでは「1日」と「1週間」）のしごとを、あらかじめ計画して、やりきるひとくぎり |
| ベロシティ | さいきん3日間で、おわったしごとの量（pt）の平均。「きょうはこのくらいできそう」のめやす |
| 約束pt | きょうの計画で「ここまでやる」ときめた量。pt は、しごとの大きさをあらわす数字（時間ではなく、ほかのしごととくらべてきめる） |
| PDCA | 計画（Plan）→ 実行（Do）→ 確認（Check）→ 改善（Act）を、ぐるぐるくりかえす進め方 |
| KPT | ふりかえりの型。よかったこと（Keep）・こまったこと（Problem）・つぎにためすこと（Try）の3つを書く |
