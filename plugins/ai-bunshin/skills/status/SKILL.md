# タスク状況の確認

1. `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/update_dashboard.py"` を実行する（Excel とタスクボードが更新される）
2. 出力をもとに、本人に次の形で短く報告する：

```
📋 タスク状況（M/D）
- 全体の完了予定：M/D(曜)
- 🔴 期限超過：N件 / ⚠ 遅延見込み：N件
- 現在のスプリント：S###「ゴール」— 進捗 N%（PDCA：◯◯）

優先順位トップ5
1. T0XX タイトル（担当）— 完了予定 M/D
…

要対応：（期限超過・遅延見込みのタスクと、対処案）

📌 <呼び方>へのお願い（N件）
- T0XX [判断] 内容
- T0XX [申請] 内容
（手順は 00_タスク管理/<呼び方>へのお願い.md にあります）
```

3. 期限超過や遅延見込みがあれば、対処案（順位の入れ替え、分割、部下の並列化など）を1〜2個添える
4. スクリプトが「Excel で開かれているため保存できませんでした」と言った場合は、ファイルを閉じてもらうよう伝える

詳細は `00_タスク管理/タスク管理.xlsx` を開けば見られる、と案内する。
