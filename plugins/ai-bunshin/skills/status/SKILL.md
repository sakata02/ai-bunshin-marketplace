## ことばの説明（本人に聞かれたとき・報告に使うときに添える）
<!-- 出力 -->
**シンプルのとき**（会話の中で一番新しい「[見せ方：…]」の行がシンプルのとき。決まりの正は `.claude/ai-bunshin-details/display.md`）：言葉を言い換えて出すので、この説明は添えない（フルだけ）。本人が「◯◯って何？」と聞いたときだけ、この表をその場で見せる（設定は変えない）。フル、またはその行が無いときは、下の今までの形のまま。

報告や Excel に出てくる言葉は、本人がエンジニアでなくても分かるように、使うときに次の言い方で一言添える。聞かれたら表ごと見せる。

| ことば | 意味（ひらがな多め） |
|---|---|
| スプリント | きめた期間（ここでは「1日」と「1週間」）のしごとを、あらかじめ計画して、やりきるひとくぎり |
| ベロシティ | さいきん3日間で、おわったしごとの量（pt）の平均。「きょうはこのくらいできそう」のめやす |
| 約束pt | きょうの計画で「ここまでやる」ときめた量。pt は、しごとの大きさをあらわす数字（時間ではなく、ほかのしごととくらべてきめる） |
| PDCA | 計画（Plan）→ 実行（Do）→ 確認（Check）→ 改善（Act）を、ぐるぐるくりかえす進め方 |
| KPT | ふりかえりの型。よかったこと（Keep）・こまったこと（Problem）・つぎにためすこと（Try）の3つを書く |
