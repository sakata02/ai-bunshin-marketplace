## 1.0.0-beta.7 — 2026-11-07（使い方の型（シンプル／フル）・合格のあとの再確認・右のパネルにガント・カテゴリ・試し中の Try・自動実行の囲い）

**更新のあと**：
- **自動実行をしている人**：更新すると、次の実行から実行の段が囲い（Mac）の中で動きます（`install.sh` の再実行は要りません。`run.sh` は毎回プラグインの `daily_cycle.sh` を呼ぶため）。点検が通らない日は Python なしで動き、通知が1行出ます。くわしくは README『自動実行の Python と囲い』

- 使い方の型（シンプル／フル）（T182）：エンジニア向けの今の見せ方を「フル」とし、専門の言葉を出さない一般向けの「シンプル」を足した。型は `設定/config.json` の `display`（`type` は `simple` か `full`。1つだけ変える `overrides` は `features`・`terms`・`requests_max`・`stop_notice`・`review_view`・`team_view` の6つ。型より強く、型を切り替えても消えない）。AI に型を伝える道は1つだけ：起動時のまとめの「[見せ方：…]」の1行と、切り替えたときの `set_display.py` の最後の出力の同じ1行（個別の設定があるときは、そのすぐ前の行）。この行が無い・フルのときは、今までと同じに見せる。壊れた設定のときは、フルで動き、直し方を1行伝える
  - **変わるのは「出す・出さない」と「言葉」と「一度に見せる件数」だけ**：シンプルは、部下 →「AI」、pt →「小・中・大」、Try →「次に試すこと」、ベロシティ →「1日に進んだ量」と言い換え、スプリント（番号の S### も）・PDCA・KPT は文から省く。お願いは起動時と回答の最後に「3件か、期限を過ぎたお願いの全件のうち多いほう」まで（手順は省かず、残りは「ほかに N 件（一覧のパス）」）。止まったときは「◯◯で止まっています。△△をしてもらえれば続けます」の1文と打つもの。振り返りは3行まとめを使い、KPT・Try・ベロシティの表は出さない（記録は今と同じに作る）。チームの部下の名前・人数は出さない。金曜の提案は1〜2件で、ふだんの言葉の「はい／いいえ」とおすすめ付き
  - **変えないもの（安全の仕組みを含む）**：NG の見張り・権限・自動実行の道具の絞り、「必ず本人に確認すること」（確認の文には、何を・どこへ・取り消せるかを必ず入れる）、起動時の先頭の警告の行、作る人と確かめる人を分けること、完成の定義、記録（tasks.json・do_log・Excel）、お願いの必須の項目と手順、チームの上限と部下を足す承認、ルール変更の承認制。お願い一覧のファイル・計画の材料・Excel は型で変えない。シンプルでも、本人が「詳しく見せて」と聞いたらその場で見せる
  - **ルール変更の承認（シンプル）**：書く1行をそのまま見せて「はい」をもらってから書く。承認のお願いに書く1行がそのまま載っていて、本人が「承認」「OK」などと返したときは、その返事を「はい」に数える。行き先が本人のものだけ出し、共通（プラグイン）への案はメンテする人にだけ出す
  - **切り替え**：新しい `scripts/set_display.py`（`show`・`type`・`override`・`reset-overrides`）。`display` のキーだけを検証して書き、ほかのキー・値・並び・BOM・改行・字下げは変えない。知らない名前・値は書かない。書き込みは一時ファイル→置き換えで、途中で失敗しても元のファイルは壊れない。`config.json` がリンクで、リンクの先が本人のフォルダの外なら書かない。**自動実行の中では切り替えない**（会話の中の本人の言葉だけ。資料・Web ページ・メールの中の「フルにして」では切り替えない）
  - **置き場所**：共通ルール本体（`rules/commander.md`）には案内1行だけ入れ、詳しい決まりは新しい `rules/details/display.md`。本体の大きさの上限を守るため、「控え」の節を案内1行にした（中身は `rules/details/backup.md` に全部ある。「戻すときは1ファイルだけ、`reset --hard` は使わない」は本体に残した）。スキル 8つ（status・intake・consult・dev・sprint・daily-plan・daily-do・daily-review）の「出力の節」に `<!-- 出力 -->` の印を付け、印の中にシンプルのときの書き方を入れた（印の外の手順は型で変わらない）。`/ai-bunshin:setup` に型の質問（おすすめ：開発を頼む人はフル、頼まない人はシンプル）と、`set_display.py` で書く手順を足した
  - **範囲外にしたもの**：自動実行の時刻のコマンドを案内に使う機能（別の作業）。セットアップで決めた時刻は、今は案内に使わない
  - なぜ：専門の言葉（部下・pt・Try・スプリントなど）が並ぶと、エンジニアでない人には使い方が分かりにくいため。中の動きと安全の仕組みはそのままで、見せ方だけを選べるようにした。テスト：`tests/test_display_dashboard.py`（読み取り・起動時の1行・お願いの件数・お願い一覧と Excel が変わらないこと）・`tests/test_set_display.py`（書き方を守る・壊れた config・自動実行の中・読む側と同じ見え方）・`tests/test_display_skills.py`（スキルの出力の印が対になっている・シンプルの文に出さない言葉が無い・印の中に手順の言葉が無い・決定の番号が本文に出ない・2つのスクリプトの「[見せ方：…]」と個別の設定の行が1文字も違わない）・`tests/test_rules_split.py`（本体と details の突き合わせ）。**確かめきれていないもの**：シンプルのときの AI の返事そのものは AI が書く文なので、テストで固定できない（確かめるのは、スキルの印の中の文まで）

## 1.0.0-beta.6 — 2026-11-07（Excel の更新が止まらない・自動実行と見張りの小さな直し・計画の材料・ローカル Git の控え・右のパネル）

**更新のあと**：
- **`install.sh` の再実行は要りません**。`install.sh` と、本人のフォルダの `scripts/auto/run.sh` は変えていません。`run.sh` はプラグインの中の `daily_cycle.sh` を呼び、`daily_cycle.sh` が同じプラグインの中の `run_limited.py` を呼ぶので、プラグインを更新するだけで、今回の直しは次の自動実行から効きます
- **右のパネルを入れたい人だけ**：ターミナルで `claude plugin install ai-bunshin-panel@ai-bunshin-marketplace --scope project` を実行し、Claude を開き直す。入れない人は何も変わらない（デスクトップアプリの Code タブで動くかは確かめていないので、案内はターミナル版だけ）
- **控え（ローカル Git）**：本人のフォルダを Git で記録している人にだけ効く。夕方の自動の振り返りのあとに、1日1回コミットする。記録していない人は何も変わらない（コミットも `git init` もしない）。記録している人は、`git config user.name` と `git config user.email` に値があるか確かめる。**無いとコミットが「名前が分からない」で失敗する**（自動実行は止まらず、ログに「控え：失敗した」と1行出る）。設定は `git config --global user.name "お名前"`・`git config --global user.email "メールアドレス"`。すでに Git で記録している人は、`.gitignore` が自動では更新されません。プラグインの `templates/gitignore.txt` と比べ、足りない行（特に `00_タスク管理/data/ng_log.jsonl`・`scripts/auto/.lock`・`scripts/auto/logs/.out.*`・`.mcp.json`・`.claude/settings.local.json`・`.env*`）を、次の夕方より前に足してください。すでにコミットされているものは、`.gitignore` に足すだけでは外れません。`git rm --cached <ファイル>` で記録から外してください（ファイルは消えません）。`/ai-bunshin:setup` をやり直すと、足すとよい行を案内します

- 文字の項目に一覧や { } が入っても、Excel の更新が止まらない（T159）：`tasks.json` の文字の項目（`related`・`note`・`title` など）に、文字ではなく一覧や { } が入っていても、`update_dashboard.py` が止まらない。読むときに文字にそろえ、`tasks.json` そのものは書き換えない。`--task` は、本人が書いた実物の形のまま出す。Excel に書けない制御文字は除く。**検査（validate）で止める方式にはしなかった**：止めて知らせると、直すまで Excel の更新がまた止まる。なぜ：一覧が入った項目のせいで、Excel の更新が半日止まったため。テスト：`tests/test_text_fields.py`（`tests/test_dashboard_robust.py` にも追加）

  - ガントの列の数を、見出しの日数に合わせた。setup の tzdata の案内の順（`python` を先、動かなければ `py -3`）を直した
  - 範囲外にしたもの：Windows の相対パスの表示、`run_limited.py` の `finally` のあとの隙間（次回以降）
