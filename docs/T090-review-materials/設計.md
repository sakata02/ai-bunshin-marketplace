# T090 振り返りの材料を広げる — 設計

作成：指揮官／確かめ：部下D／実装：部下C

## ゴール（なぜ）
業務改善の提案が0件のまま。`--review-context` の「改善の材料」が主に AI のタスクを見ていて、本人の実際の業務が入っていないため（T085 の設計の A-1 のスクリプト部分）。

## 変えるもの
- `plugins/ai-bunshin/scripts/update_dashboard.py` の `improvement_candidates()` と、その下請けの関数
- 新規 `plugins/ai-bunshin/tests/test_review_materials.py`

## 今あるもの（残す）
「繰り返している仕事」「手作業らしい仕事」「本人設定の定例業務」（config の `regular`）「提案の一覧」の4行と、その計算。金曜だけ出す条件、OPEN/SKIP の判定。
